# 开始使用

## 你现在可以提供什么

任选一种即可开始，不需要整理成 JSON，也不需要先安装 LaTeX：

- 一份已有简历（PDF、Word、Markdown 或纯文本）；
- 一个目标岗位 JD；
- 项目说明、GitHub 仓库、论文或作品链接；
- 一段自然语言介绍，例如“我是校招生，想投 Agent 开发”。

## Agent 首轮要做什么

1. 读取已有材料，不重复询问材料里已经写明的内容；
2. 判断候选阶段与当前目标，只启用需要的简历方向；
3. 定义目标 Offer，返回材料清单、首版岗位定位、最多 3 个高价值缺口；
4. 先给可审阅草稿，再让用户一次性确认事实与改写；
5. 用户确认后再生成最终简历或其他按需产物。
