# Agent Career Kit Public Showcase

This directory contains generated public demonstration artifacts for Agent Career Kit. It is a template fixture, not a real candidate profile, employment history or hiring result.

The resume layout and template case are derived from [adongwanai/LLM-Resume-Template](https://github.com/adongwanai/LLM-Resume-Template) at commit `9673d5baeec3d8c54611d0e0d1040495cbca8989`, whose README identifies the resume content as [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The generated resumes and portfolio add a visible fixture disclosure and were produced by Agent Career Kit.

The included experiences, education, publications, companies, awards and metrics demonstrate rendering and workflow behavior only. Replace all of them with candidate-owned evidence before real use.

`agent-career-workflow.svg` / `agent-career-workflow@2x.png` and `agent-career-architecture.svg` / `agent-career-architecture@2x.png` are the reproducible workflow and architecture diagrams for this showcase.
