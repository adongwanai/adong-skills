## 口播脚本

大家准备 Agent 开发、Agent 算法岗位的时候，最大的问题其实不是不会改简历。

而是所有东西都是散的：简历一份、GitHub 一堆项目、JD 一堆关键词、面试题一堆八股，面完之后复盘也丢了。下次投递，又从零开始。

所以我最近做了一个 Skill，叫 **Agent Career Kit**。

它的思路很简单：先把你的简历、GitHub、项目、论文、JD、面试记录，沉淀成一份长期候选人档案。后面所有动作都从这份档案出发。

它能做几件事。

第一，帮你做简历审计。不是简单润色，而是按 30 秒筛选、项目难点、个人贡献、技术决策、结果证据，一条条看你哪里没讲清楚。

第二，它可以生成两类稳定简历：**Agent 开发版**和 **Agent 算法版**。开发版突出工具调用、工作流、评估、可靠性；算法版突出模型、训练、检索、实验和指标。

第三，它有模拟面试。可以单独深挖一个项目，也可以跑 45 到 60 分钟完整流程：自我介绍、项目深挖、Agent 八股、Coding、系统设计、反问。一次只问一题，像 grill-me 一样往下追。

第四，它还能做作品集、GitHub README、个人求职页、JD 投递包、Offer 跟踪和面后复盘。

我最看重的不是“生成了多少文件”，而是它把求职从一次性突击，变成了一个可以持续迭代的系统。

你可以从一份旧简历开始，也可以从一个 GitHub 项目或者一个 JD 开始。目标很直接：帮助做 Agent 的同学，把材料、项目和面试准备都系统化，去冲刺更高质量的 Offer。

项目已经开源，支持 Codex、Claude Code 和 OpenCode。感兴趣可以去 GitHub 看 `adong-skills` 里的 `agent-career-kit`。

如果你还想系统学 Agent 工程、项目实战和面试题库，也可以关注我的另一个仓库：**AgentGuide**。
