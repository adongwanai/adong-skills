# 配图大纲

## 01 原布局上的当前核心工作流

- 任意材料冷启动 → 建立个人主档案 → 开发 / 算法能力画像。
- 并行分支：按需简历 PDF；项目与学习补强。
- 汇合：JD 快照与作品集 → Coding 与模拟面试 → Offer 驾驶舱与复盘。
- Offer 驾驶舱与复盘回写能力画像。
- 原则：主档案长期稳定、JD 快照独立、复盘持续回写。
