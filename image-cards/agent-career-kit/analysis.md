# 内容分析

## 目标与受众

把原有深色工程图改成明亮、可扫读的产品介绍图，面向首次在 GitHub 了解本 Skill 的 Agent 开发与 Agent 算法候选人。

## 视觉策略

- 浅灰白背景，深色正文，高对比度。
- 蓝、青绿为主强调色，少量暖黄表示反馈闭环。
- 扁平二维信息图，不使用深色大底、霓虹、3D、复杂纹理或渐变。
- 卡片边界清楚，留白充足，箭头粗细一致。
- 中文必须完整、清晰，不添加提示词之外的文案。

## 两张图的分工

1. 流程图：材料进入事实档案，形成双简历、项目训练、作品集与面试，再通过复盘回写。
2. 介绍图：八个可独立调用的核心能力、双岗位方向、跨客户端支持和事实约束。
